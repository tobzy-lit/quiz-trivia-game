# Quiz Master 🎯

Quiz Master is a simple command-line trivia game built with Python. It tests players with questions, checks their answers, and calculates their final scores.

## Features

- Randomizes the order of questions.
- Provides multiple-choice answers.
- Validates user input.
- Gives feedback on correct and incorrect answers.
- Calculates the player's final score and percentage.

## Technologies Used

- Python 3
- Python Standard Library (`random` module)

## Requirements

- Python 3 installed on your computer.
- A terminal or command-line interface.

## How to Run

1. Clone this repository.
2. Open the project directory in your terminal.
3. Run the following command:

   python3 main.py

## How to Play

1. Enter your name.
2. Read each question and its options.
3. Enter your answer (A, B, C, or D).
4. Check your score at the end of the quiz.
